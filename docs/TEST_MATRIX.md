# 驗證範圍與重跑方式

## 自動驗證

```powershell
npm test
npm run typecheck
npm run lint
npm run build
npm run check:secrets
npm run test:e2e
```

預設測試不付費。Vitest（單元／整合測試）使用暫存 SQLite（單檔資料庫）及模型配接器模擬。React Testing Library（元件行為工具）驗證模式讀取與原文保存同意／排除。Playwright（瀏覽器測試）使用獨立、無金鑰的固定模式目錄及系統 Chrome，不修改本人的 .env（本機設定）。

| 情境 | 自動證據 | 仍需人工判斷 |
|---|---|---|
| 正確／不存在／不唯一引用 | sources.test.ts（來源測試） | 引用是否支持語意 |
| 中文、表情與組合字元 | 精確原文切片比對 | 高亮閱讀前後文 |
| 空白、超長、版本錯誤 | 資料契約及上游前拒絕 | 合理縮小輸入範圍 |
| 行動／網頁／Next.js（網頁框架）混淆 | 平台保護與合成標註 | 證據的实际平台與責任 |
| 年資不明／不足／時間重疊 | 禁止日期推算，降為確認 | 能否補充明示技能期間 |
| 矛盾條件／經歷 | 原文衝突傳入及保守確認 | 矛盾來源是否全部擷取 |
| 模型新增數字、技術、責任與成果 | 字詞／主張覆蓋，後端接受阻擋 | 文字語意及因果是否擴大 |
| 憑證、參數、限流、逾時、斷線、格式及截斷 | provider-faults.test.ts（服務故障測試）及已計費無效回應 | 真實供應商權限及服務穩定性 |
| 取消、重啟、清除及遲到回應 | runs.test.ts（執行管理）、整合與乾淨重建 | 平台備份及磁碟底層無法保證抹除 |
| 收藏、搜尋篩選與比較 | 瀏覽器流程，含完整鍵盤操作及人工核對恢復 | 長期大量職缺使用體驗 |
| 一次確認履歷後整批比對 | 全部職缺自動進入整批處理、卡片結果入口一致、補充來源歸屬履歷區、跨頁選擇延續、切換履歷不混用摘要及過期結果 | 初次使用者能否理解「確認履歷後會比對整份清單」 |
| 重複接受、拒絕及還原 | 交易防重複及畫面操作 | 人工接受內容本身正確性 |
| 鍵盤、焦點、各尺寸、縮放、空錯誤載入 | 實際瀏覽器及 axe-core（無障礙掃描） | 螢幕閱讀器、Safari、實機手機未測 |
| 金鑰不進瀏覽器產物 | 掃描已設定金鑰的字面值 | 不宣稱涵蓋所有形式的資安掃描 |

## AI 評估與付費入口

tests/cases.ts（人工預期案例）含二十四組原文與預期狀態，十六組開發、八組保留。上述額外故障、來源及改寫矩陣也以單元／整合覆蓋，不能以固定模式案例的通過數冒充真實模型品質。

```powershell
npm run evaluate
npm run evaluate:live
npm run compare:models
npx tsx scripts/live-browser.ts
```

前三項分別是固定模式、真實全案例及兩個候選各六案例。後兩項與真實全案例均會付費，採序列及本機流量上限，不與其他真實測試同時執行。評估結果與完整合成內容留在 docs/evidence（可分享證據），憑證只在隔離暫存設定，完成後刪除。

模型比較以全部已知費用除以合格案例數，另列費用未知請求。被來源／事實檢查擋下不算成功；暫時服務失敗也保留。模型較便宜的單價不等於每個合格結果成本較低。

正式原始結果、人工語意核對結論、最慢／中位耗時、樣本數及費用以 docs/STATUS.md（實測狀態）為準。小樣本不宣稱可靠百分位或泛化正確率。

唯讀檢查目前本機首頁可執行 npx tsx scripts/inspect-home.ts（首頁畫面檢查）。它保存四個尺寸截圖並確認補充來源位置、文件數未變及沒有新增模型請求，不清除範例或使用者資料。

整批新增驗證：核對一次履歷後三職缺全出結果、統一入口、不冒稱職缺已人工確認、再次更新沿用有效快取、部分失敗仍繼續、取消／重新啟動不自動付費、履歷修改停止及清除不復活。真實整批以 scripts/live-batch-browser.ts（實際瀏覽器腳本）明確啟動，會產生付費請求；只允許既有合成資料，不列入預設測試。

錄影使用 scripts/recording-environment.ts（隔離環境），始終建立空白資料庫與 http://localhost:3002，不清除本人資料。真實錄影會產生付費請求，包含三份職缺的整批比對、改寫與獨立核查；固定錄影不付費。完成或失敗後刪除隔離金鑰設定，保留無金鑰資料庫供費用去重。整批任務內的唯一一次修復也等待每分鐘額度；回歸測試驗證等待與取消沒有額外請求。

```powershell
npx tsx scripts/record-demo.ts
npx tsx scripts/serve-recordings.ts
# 另開終端，驗證兩份影片播放、字幕、鍵盤切換與四尺寸面積
npx tsx scripts/inspect-recordings.ts
```

播放器驗收讀取錄影，不呼叫模型；確認實際解碼、影片跳轉、可見面積至少 50%、無水平溢出、無障礙掃描及允許檔案清單。手機尺寸模擬不代表手機實機。
