# 三分鐘操作影片腳本

影片是合成資料，不代表真實工作經歷。主要影片可使用固定模式，畫面永久顯示「固定範例 · 非真實 AI」。真實模型流程另保留錄影及逐次費用，既有結果不可假裝現場生成。

| 時間 | 操作與旁白 |
|---|---|
| 0:00–0:20 | 工作台：「這是個人本機作品；上方選擇比對履歷，補充來源也在履歷區，下方是用這份履歷評估的職缺。畫面正在使用固定範例。」載入合成資料。 |
| 0:20–0:45 | 只提取並核對一次履歷事實，確認後自動比對全部職缺：「提取由模型處理，使用者核對原文與必要／加分分類；職缺會依序自動處理，不需逐筆操作。」點引用看高亮。 |
| 0:45–1:15 | 首頁查看全部職缺的完成數與卡片摘要，從統一「查看比對結果」入口進入，再核對這份職缺條件：「每項要求獨立判斷。有證據回到履歷原文；行動經驗不直接折算為網頁年資。」 |
| 1:15–1:40 | 查看加分缺口：「未提及不代表沒有能力；建議補充作品是下一步，不能當現有成果。」 |
| 1:40–2:15 | 改寫：「選一段原文，前後並列。每個主張有依據，真實模式另由獨立模型核查；程式阻擋無來源數字與責任升級。」 |
| 2:15–2:40 | 接受並還原：「只有本人接受才修改，保存修訂紀錄，隨時還原；已接受文字不變成新事實來源。」 |
| 2:40–3:00 | 資料與用量：「金鑰只在伺服器，資料本機保存，可清除；真實請求保留實測費用，固定範例不算 AI 驗收。」 |

實際錄影由 scripts/record-demo.ts（瀏覽器錄影腳本）產生，固定範例新版長度約 2 分 57 秒。無人工配音，附 VTT（字幕檔）繁體中文字幕；旁白可依表逐段錄製。真實新版由 scripts/live-browser.ts（付費瀏覽器錄影）產生，使用全新隔離的合成資料，依原速保留等待與費用，檔名為 evidence/video-live/batch-live-flow.webm（整批完整錄影）。

依日常操作的完整步驟另見 USER_GUIDE.md（使用指南）。

播放時執行 npx tsx scripts/serve-recordings.ts（本機影片服務），開啟 http://localhost:3003。播放器在可見畫面中至少占一半，模式切換不呼叫模型。舊版錄影另存歷史，不列為新版展示。真實影片只有全流程完成才更新正式檔案；失敗畫面及已發生費用分開保留。
